# Registry Persistence Activity Detection

## Detection

Wazuh detected Windows Registry key deletion activity.

Rule ID:
597

Rule Description:
Registry Key Entry Deleted

Severity:
5

---

## Why It Matters

Registry modifications are frequently used by attackers to:

- Maintain persistence
- Hide malware
- Disable security controls
- Remove traces after execution

Monitoring registry activity allows analysts to identify suspicious persistence attempts and system modifications.
